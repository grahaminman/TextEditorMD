# Welcome to TextEditorMD

This is a **CommonMark** Markdown editor. The live preview on the right follows the [CommonMark](https://commonmark.org/) specification.

## Basics

- *Emphasis* with single asterisks or `_underscores_`
- **Strong** with double asterisks or `__underscores__`
- `Inline code` with backticks
- [Links](https://commonmark.org/) with brackets and parentheses

### Lists

   - Another nested item

## Tips

- **Save** — Ctrl/Cmd+S  
- **Find** — Ctrl/Cmd+F  
- **Toggle preview** — Ctrl/Cmd+P  

Use **View → Syntax colours…** to customise editor highlighting, and **Theme** for light / dark / system modes.

Happy writing.
